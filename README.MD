# 🚀 快速入门

## 系统要求

| 项目 | 最低要求 |
|------|----------|
| 操作系统 | Windows 10/11 64-bit |
| 内存 | 4GB 以上 |
| Node.js | v18 或更高 |
| Git | 任意版本 |
| PowerShell | 5.1 或更高 |

## 首次启动

1. **双击** `OpenClaw Dashboard.exe` 启动应用
2. 系统自动进入**环境检测**页面，检查以下组件：
   - 🖥️ Windows 版本和系统环境
   - 💻 PowerShell 可用性和执行策略
   - 📦 Node.js 是否安装及版本号
   - 🔧 Git 是否可用
   - 🐍 Python 是否可用（可选）
   - 🔗 OpenClaw CLI 是否已安装
   - ⚙️ Gateway 配置文件是否存在
3. 根据检测结果采取不同操作：
   - ✅ **全部通过** → 自动进入主界面
   - ⚠️ **有警告项** → 可选择修复后进入
   - ❌ **致命错误** → 必须修复才能启动
4. 进入主界面后，点击顶部 **▶ 启动** 按钮启动 Gateway 服务

👑 太子（总协调）
    ↓
🏛️ 三省（决策层）

    └── 📮 尚书省（派发协调）
    ↓
⚙️ 六部（执行层）
    ├── 💰 户部（数据执行）
    ├── 📝 礼部（文档执行）
    ├── ⚔️ 兵部（工程执行）
    ├── ⚖️ 刑部（合规审查）
    ├── 🔧 工部（基础设施）
    └── 📋 吏部（人事管理）

## Cron 表达式示例

| 表达式 | 含义 |
|--------|------|
| `*/15 * * * *` | 每 15 分钟 |
| `0 * * * *` | 每小时整点 |
| `0 */6 * * *` | 每 6 小时 |
| `0 8 * * *` | 每天 08:00 |
| `0 9 * * 1-5` | 工作日 09:00 |

# 🤖 模型

管理所有 AI 模型和 Provider（服务商）。

## 模型分类

### 📝 文本模型 (agents.defaults.model)
- 用于文本对话的模型
- 可设置为主模型和备用模型
- 支持批量检测所有文本模型

### 🖼️ 多模态模型 (agents.defaults.imageModel)
- 用于处理图像和多模态内容的模型
- 可设置为主模型和备用模型
- 支持批量检测所有多模态模型

### 📦 所有可用模型
- 显示所有已配置的模型
- 按 Provider 分组展示

## 添加模型

### 方式一：快速添加

1. 点击「＋ 添加模型」
2. 展开「⚡ 热门模型快速添加」
3. 选择预设模型，点击「+ 添加」
4. 如需新 Provider，填写 API Key

### 方式二：手动添加

1. 选择或新建 Provider
2. 填写 Model ID 和显示名称
3. 点击「🧪 测试」验证
4. 确认添加

## 设置主模型

| 按钮 | 作用 |
|------|------|
| 📝 主模型 | 设为文本对话主模型 |
| 🖼️ 主模型 | 设为图像/多模态主模型 |
| 📝 +备用 | 添加到文本备用列表 |
| 🖼️ +备用 | 添加到多模态备用列表 |

**自动故障转移**：主模型不可用时自动切换到备用模型。

## 支持的服务商

OpenRouter、OpenAI、Anthropic、Google(Gemini)、DeepSeek、Moonshot(Kimi)、智谱(GLM)、Qwen(通义千问)、Ollama、LM Studio 等 30+ 服务商。

## 模型测试

- 系统会直接从 `%USERPROFILE%\.openclaw\openclaw.json` 文件中读取 API Key
- 支持本地和云端模型的测试
- 本地模型只检测端口是否可访问
- 云端模型会发送测试请求验证 API Key 和模型是否可用
- 支持批量检测所有文本或多模态模型

# ❓ 常见问题

## Gateway 无法启动

1. 检查端口占用：`netstat -ano | findstr 18789`
2. 结束占用进程：`taskkill /PID <PID> /F`
3. 运行「🔍 环境状态 → 📋 诊断」
4. 检查配置文件语法
5. 尝试「🔄 重启」

## WebSocket 连接失败

1. 确认 Gateway 已启动
2. 检查防火墙设置
3. 验证 WS 认证配置
4. 重启 Gateway

## 状态卡片显示异常

- 确认对应服务已启动
- 状态每 5 秒自动刷新
- 手动刷新：切换标签页后返回

## 中文乱码

1. 点击「🌐 全局UTF-8」按钮
2. 重启 Dashboard
3. 系统区域设置勾选「Beta: 使用 Unicode UTF-8」

## 模型返回 "is not allowed"

在配置文件的 `agents.defaults.models` 中添加该模型白名单。

## 会话历史不显示

1. 等待 Gateway 完全启动
2. 刷新页面重新加载
3. 运行 `openclaw doctor --fix`
